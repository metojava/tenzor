1. Overview

What is the scikit-learn-like API?

Tenzor provides a familiar scikit-learn-like API for traditional machine learning algorithms. This includes classification, regression, preprocessing, model selection, and dimensionality reduction.

CategoryAlgorithms
ClassificationLogistic Regression, Random Forest, Decision Tree, SVM, KNN, AdaBoost, Gradient Boosting
RegressionLinear, Ridge, Lasso, ElasticNet, Random Forest, Decision Tree, SVM, KNN, Gradient Boosting
PreprocessingStandardScaler, MinMaxScaler, RobustScaler, Normalizer, OneHotEncoder, LabelEncoder, SimpleImputer
Model Selectiontrain_test_split, KFold, StratifiedKFold, GridSearchCV, cross_val_score
DecompositionPCA, IncrementalPCA

2. Typical Workflow

Standard ML Pipeline

// 1. Load data
Iris iris = new Iris();
Tensor X = iris.getFeatures();
Tensor y = iris.getTarget();

// 2. Split data
Tensor[] split = train_test_split.split(X, y, 0.3, 42);

// 3. Preprocess
StandardScaler scaler = new StandardScaler();
Tensor X_train = scaler.fitTransform(split[0]);
Tensor X_test = scaler.transform(split[1]);

// 4. Train model
RandomForestClassifier model = new RandomForestClassifier(100, 10, 2);
model.fit(X_train, split[2]);

// 5. Predict
Tensor predictions = model.predict(X_test);

// 6. Evaluate
double accuracy = Accuracy.compute(split[3], predictions);

3. Preprocessing

3.1: Scalers

ScalerPurposeWhen to Use
StandardScaler Standardize features by removing mean and scaling to unit variance Most algorithms (SVM, KNN, Neural Networks)
MinMaxScaler Scale to [0, 1] range Neural networks, bounded range needed
RobustScaler Robust to outliers using median and quartiles Data with outliers
Normalizer Scale samples to have unit norm Text processing, sparse data

4.2: Classifier Comparison Example

Map<String, Double> results = new LinkedHashMap<>();

// Logistic Regression
LogisticRegression logReg = new LogisticRegression(0.01, 1000);
logReg.fit(X_train, y_train);
results.put("Logistic Regression", 
    Accuracy.compute(y_test, logReg.predict(X_test)));

// SVM
SVC svc = new SVC(1.0, "rbf");
svc.fit(X_train, y_train);
results.put("SVM", 
    Accuracy.compute(y_test, svc.predict(y_test)));

// KNN
KNeighborsClassifier knn = new KNeighborsClassifier(5);
knn.fit(X_train, y_train);
results.put("KNN", 
    Accuracy.compute(y_test, knn.predict(X_test)));

// Print results
for (Map.Entry<String, Double> entry : results.entrySet()) {
    System.out.printf("%s: %.4f%n, entry.getKey(), entry.getValue());
}

6. Model Selection

6.1: train_test_split

// Basic split (70% train, 30% test)
Tensor[] split = train_test_split.split(X, y, 0.3, 42);

// split[0] = X_train
// split[1] = X_test
// split[2] = y_train
// split[3] = y_test

// With stratification (for classification)
StratifiedKFold skf = new StratifiedKFold(5, 42);

6.2: K-Fold Cross-Validation

// 5-fold CV
KFold kfold = new KFold(5, 42);
List<Tensor[]> folds = kfold.split(X, y);

double[] scores = new double[folds.size()];

for (int i = 0; i < folds.size(); i++) {
    Tensor[] fold = folds.get(i);
    
    // fold[0] = X_train for this fold
    // fold[1] = X_test for this fold
    // fold[2] = y_train for this fold
    // fold[3] = y_test for this fold
    
    RandomForestClassifier model = new RandomForestClassifier(100, 10, 2);
    model.fit(fold[0], fold[2]);
    
    scores[i] = Accuracy.compute(fold[3], model.predict(fold[1]));
}

double meanScore = Arrays.stream(scores).average().getAsDouble();
System.out.println("Mean CV Accuracy: " + meanScore);

ChartUtils.plotScatter(pc1, pc2, 
    "PCA Visualization",
    "PC1", "PC2",
    "output/pca.png");
When to use PCA?
  • Visualization: Reduce high-dimensional data to 2D/3D
  • Speed: Reduce feature count before training
  • Noise reduction: Remove noisy features
  • Before: Always scale your data before PCA!

8. Metrics

8.1: Classification Metrics

MetricFormula/Description
Accuracy(TP + TN) / (TP + TN + FP + FN)
PrecisionTP / (TP + FP) - how many predicted positives are correct
RecallTP / (TP + FN) - how many actual positives found
F1 Score2 * (Precision * Recall) / (Precision + Recall)
 
double accuracy = Accuracy.compute(y_true, y_pred);
double precision = Precision.compute(y_true, y_pred);
double recall = Recall.compute(y_true, y_pred);
double f1 = F1Score.compute(y_true, y_pred);

8.2: Regression Metrics

MetricFormula
MSEmean((y_true - y_pred)²)
MAEmean(|y_true - y_pred|)
MAPEmean(|(y_true - y_pred)/y_true|) * 100
R² Score1 - (SS_res / SS_tot)
 
double mse = MeanSquaredError.compute(y_true, y_pred);
double mae = MeanAbsoluteError.compute(y_true, y_pred);
double mape = MeanAbsolutePercentageError.compute(y_true, y_pred);
double r2 = R2Score.compute(y_true, y_pred);
