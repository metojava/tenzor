Tensor - Core Data Structure

Tensor: An N-dimensional array of doubles. The fundamental data structure for all ML operations.

Creating Tensors

new Tensor(double[] data)
double[] vecData = {1.0, 2.0, 3.0};
Tensor vector = new Tensor(vecData);  // Shape(3)
new Tensor(double[][] data)
double[][] matData = {{1,2}, {3,4}, {5,6}};
Tensor matrix = new Tensor(matData);  // Shape(3, 2)
new Tensor(double[] flatData, Shape shape)
Tensor tensor3d = new Tensor(flatArray, new Shape(100, 30, 5));
// 100 samples, 30 time steps, 5 features (LSTM input shape)

Factory Methods

Tensor.zeros(Shape)

Create tensor filled with 0.0

Tensor.ones(Shape)

Create tensor filled with 1.0

Tensor.random(Shape, min, max)

Uniform random values in [min, max)

Tensor.randn(Shape, mean, std)

Normal (Gaussian) distribution

Sequential - Model Builder

Sequential: A linear stack of layers. The simplest way to build a neural network - just add layers one after another.

Basic Workflow

new Sequential()
Sequential model = new Sequential();

model.add(new Dense(128, "relu"));    // Hidden layer
model.add(new Dropout(0.2));           // Regularization
model.add(new Dense(10, "softmax"));  // 10-class output

model.compile(
    new SparseCategoricalCrossentropy(),  // Loss function
    new Adam(0.001)                      // Optimizer
);

ExecutionMatrix history = model.fit(
    xTrain, yTrain,
    50,      // epochs
    32,      // batch size
    0.001,   // learning rate
    0.15     // validation split
);

Tensor predictions = model.predict(xTest);
model.printEvaluation(xTest, yTest);
Epoch: One full pass over all training data. Batch size: Number of samples per gradient update. Validation split: Fraction of data held out for monitoring overfitting.

Dense Layer Pattern

model.add(new Dense(64, "relu"));     // Hidden: ReLU
model.add(new Dense(1, "sigmoid"));  // Output: binary classification
model.add(new Dense(10, "softmax")); // Output: multi-class (10)
model.add(new Dense(1, "linear"));   // Output: regression
Activation Functions: Introduce non-linearity. Without them, your network is just a linear model!

ReLU: Hidden layers (most common) - max(0, x)
Sigmoid: Binary output - maps to [0,1]
Softmax: Multi-class output - probabilities sum to 1
Linear: Regression output - no transformation

Stacked LSTM for Time Series

new LSTM(int units, boolean returnSequences)
// IMPORTANT: Use returnSequences=true for stacked RNNs
model.add(new LSTM(64, true));   // Returns sequence to next layer
model.add(new Dropout(0.2));
model.add(new LSTM(32, false));  // Final RNN: returns only last output
model.add(new Dense(1));              // Regression output
LSTM Input Shape: (samples, time_steps, features)
Example: (100, 30, 5) means 100 samples, each using 30 historical time steps, with 5 features per step.

OptimizerConstructorRecommendation

Learning Rate: Controls how much to update weights in the direction of the gradient.

Too high: Model doesn't converge, loss oscillates
Too low: Training is slow, may get stuck in local minimum
Typical values: 0.001 for Adam, 0.01 for SGD 
// Typical: Adam with 0.001
model.compile(new SparseCategoricalCrossentropy(), new Adam(0.001));

// SGD with momentum
model.compile(new MeanSquaredError(), new SGD(0.01, 0.9));

Callbacks - Training Helpers

Callbacks: Objects that perform actions at different stages of training. They monitor metrics, save models, stop early, and more.
CallbackPurposeExample
EarlyStoppingStop when validation plateausnew EarlyStopping("val_loss", 10, true)
ModelCheckpointSave best model during trainingnew ModelCheckpoint("best.json", "val_loss", true)
ReduceLROnPlateauLower LR when metric stallsnew ReduceLROnPlateau("val_loss", 0.5, 5, 1e-8)

Full Callback Setup

// Create all callbacks
EarlyStopping earlyStop = new EarlyStopping(
    "val_loss",    // What to monitor
    15,             // Wait 15 epochs before stopping
    true             // Restore best weights
);

ModelCheckpoint checkpoint = new ModelCheckpoint(
    "models/best.json",
    "val_loss",
    true              // Save only on improvement
);

ReduceLROnPlateau reduceLr = new ReduceLROnPlateau(
    "val_loss",
    0.5,            // Multiply LR by 0.5
    8,              // Wait 8 epochs
    1e-8            // Don't go below this
);

// Pass to fit() as varargs
model.fit(xTrain, yTrain, 100, 32, 0.001, 0.1,
    earlyStop, checkpoint, reduceLr
);
Patience: Number of epochs to wait before taking action. Allows the model to continue training through small fluctuations.

ExecutionMatrix - Training History

ExecutionMatrix: Captures detailed training metrics per epoch: loss, accuracy, validation metrics, duration. Returned by fit().

Using ExecutionMatrix

ExecutionMatrix exec = model.fit(...);

// Print summaries
exec.printSummary();           // Best metrics, total time
exec.printEpochTable();      // All epochs table

// Get specific values
double bestValLoss = exec.getBestValidationLoss();
int bestEpoch = exec.getEpochWithBestValLoss();
long totalTime = exec.getTotalTrainingTimeMs();

// Export for analysis
exec.exportToCSV("training/log.csv");
exec.save("training/exec.bin");

// Visualize
ChartUtils.plotTrainingHistory(
    exec.toHistoryMap(),
    "Training History",
    "output/training.png"
);

scikit-learn Style API

Estimator Pattern: All traditional ML algorithms follow: fit(X, y) for training, predict(X) for predictions.

Quick Classification Example

// Split data
Tensor[] split = train_test_split.split(X, y, 0.3, 42);
Tensor X_train = split[0], X_test = split[1];
Tensor y_train = split[2], y_test = split[3];

// Preprocess
StandardScaler scaler = new StandardScaler();
X_train = scaler.fitTransform(X_train);
X_test = scaler.transform(X_test);

// Create and train model
RandomForestClassifier rf = new RandomForestClassifier(
    100,  // n_estimators
    10,   // max_depth
    2     // min_samples_split
);
rf.fit(X_train, y_train);

// Predict and evaluate
Tensor preds = rf.predict(X_test);
double accuracy = Accuracy.compute(y_test, preds);

Metrics - Evaluation

Classification Metrics

double accuracy = Accuracy.compute(y_true, y_pred);
double precision = Precision.compute(y_true, y_pred);
double recall = Recall.compute(y_true, y_pred);
double f1 = F1Score.compute(y_true, y_pred);

// Confusion matrix
ConfusionMatrix cm = new ConfusionMatrix(y_true, y_pred, numClasses);
cm.print();
Precision: Of all predicted positives, how many were correct? TP / (TP + FP)
Recall: Of all actual positives, how many were found? TP / (TP + FN)
F1: Harmonic mean of precision and recall. Good for imbalanced data.

Regression Metrics

double mse = MeanSquaredError.compute(y_true, y_pred);
double mae = MeanAbsoluteError.compute(y_true, y_pred);
double mape = MeanAbsolutePercentageError.compute(y_true, y_pred);
double r2 = R2Score.compute(y_true, y_pred);

System.out.printf("RMSE: %.4f%n", Math.sqrt(mse));
R² Score: Proportion of variance explained. Range: (-∞, 1]. 1.0 means perfect prediction, 0.0 means predicting the mean.

Time Series & Technical Indicators

Data Generation

int n = 1000;
double[] sine = SequenceGenerator.generateSineWave(n, 50, 1.0, 0);
double[] trend = SequenceGenerator.generateLinearTrend(n, 0.0, 0.002);
double[] noise = SequenceGenerator.generateRandomWalk(n, 0, 0.1);

// Combine: price-like series
double[] prices = new double[n];
for (int i = 0; i < n; i++) {
    prices[i] = sine[i] + trend[i] + 0.5 * noise[i];
}

Technical Indicators

double[] sma5 = TechnicalIndicators.simpleMovingAverage(prices, 5);
double[] sma20 = TechnicalIndicators.simpleMovingAverage(prices, 20);
double[] ema12 = TechnicalIndicators.exponentialMovingAverage(prices, 12);
double[] rsi = TechnicalIndicators.rsi(prices, 14);
double[] macd = TechnicalIndicators.macd(prices, 12, 26, 9);
double[][] bollinger = TechnicalIndicators.bollingerBands(prices, 20, 2);
double[] obv = TechnicalIndicators.onBalanceVolume(prices, volumes);

// bollinger[0] = upper band
// bollinger[1] = middle band (SMA)
// bollinger[2] = lower band

// RSI interpretation:
// > 70 = overbought (potential sell)
// < 30 = oversold (potential buy)

TimeSeriesPreprocessor preprocessor = new TimeSeriesPreprocessor();

Model Persistence - Save & Load

import com.tenzor.io.ModelSaver;
import com.tenzor.io.ModelLoader;

// Save model
ModelSaver.save(model, "models/my_model.json");

// Load model
Sequential loaded = ModelLoader.load("models/my_model.json");

// Use immediately
Tensor preds = loaded.predict(newData);

// ExecutionMatrix persistence
exec.save("training/exec.bin");
ExecutionMatrix loadedExec = ExecutionMatrix.load("training/exec.bin");
Models are saved in JSON format including: layer types, configurations, weights, and biases. Human-readable and easily inspected.

Quick Glossary

TermDefinition
TensorN-dimensional array. The fundamental data structure.
EpochOne full pass over all training data.
BatchSubset of samples used for one gradient update.
Learning RateHow much to update weights in direction of gradient.
ActivationNon-linear function that allows learning complex patterns.
OverfittingModel memorizes training data but fails to generalize.
RegularizationTechniques to prevent overfitting (Dropout, EarlyStopping).
GradientDirection of steepest ascent of the loss function. Weights are updated in the negative direction.
BackpropagationComputing gradients of loss with respect to all weights (chain rule).
LSTMLong Short-Term Memory - RNN variant that learns long-term dependencies.
BroadcastingPerforming operations on tensors of different but compatible shapes.
