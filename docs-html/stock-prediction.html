1. Overview

Disclaimer

This tutorial is for educational purposes only. Stock prediction is inherently difficult and past performance does not guarantee future results. Always consult a financial advisor before making investment decisions.

Stock Prediction Pipeline

  1. Load historical price data
  2. Compute technical indicators (SMA, EMA, RSI, MACD, Bollinger Bands, OBV)
  3. Create feature matrix with price + indicators
  4. Generate sequences for LSTM/GRU
  5. Build and train model
  6. Evaluate and visualize
  7. Backtest simple trading strategy

3.4: Bollinger Bands

Bollinger Bands Formula

  • Middle Band: 20-period SMA
  • Upper Band: Middle + 2 * standard deviation
  • Lower Band: Middle - 2 * standard deviation

Interpretation: Price near upper band = overbought, near lower band = oversold

double[][] bollinger = TechnicalIndicators.bollingerBands(prices, 20, 2);
double[] upperBand = bollinger[0];
double[] middleBand = bollinger[1];
double[] lowerBand = bollinger[2];

// Visualize all bands

bbData.add(Arrays.copyOfRange(upperBand, 20, prices.length));

4. Feature Engineering

4.1: Building Feature Matrix

int n = prices.length;
int featureCount = 10;
double[][] features = new double[n][featureCount];

double[] sma5 = TechnicalIndicators.simpleMovingAverage(prices, 5);
double[] sma20 = TechnicalIndicators.simpleMovingAverage(prices, 20);
double[] ema12 = TechnicalIndicators.exponentialMovingAverage(prices, 12);
double[] rsi = TechnicalIndicators.rsi(prices, 14);
double[] macd = TechnicalIndicators.macd(prices, 12, 26, 9);
double[][] bollinger = TechnicalIndicators.bollingerBands(prices, 20, 2);
double[] obv = TechnicalIndicators.onBalanceVolume(prices, volumes);

for (int i = 0; i < n; i++) {
    features[i][0] = prices[i];                    // Price
    features[i][1] = sma5[i];                      // SMA 5
    features[i][2] = sma20[i];                     // SMA 20
    features[i][3] = ema12[i];                     // EMA 12
    features[i][4] = rsi[i];                       // RSI
    features[i][5] = macd[i];                      // MACD
    features[i][6] = bollinger[0][i];               // Upper BB
    features[i][7] = bollinger[2][i];               // Lower BB
    features[i][8] = (prices[i] - sma20[i]) / (sma20[i] + 1e-8);  // % from SMA
    features[i][9] = obv[i];                       // OBV
}

4.2: Normalization & Sequence Creation

TimeSeriesPreprocessor preprocessor = new TimeSeriesPreprocessor();

// Normalize each feature column independently
double[][] normalizedFeatures = new double[n][featureCount];
for (int j = 0; j < featureCount; j++) {
    double[] col = new double[n];
    for (int i = 0; i < n; i++) col[i] = features[i][j];
    col = preprocessor.normalizeZScore(col);
    for (int i = 0; i < n; i++) normalizedFeatures[i][j] = col[i];
}

int sequenceLength = 15;

// Create sequences: (samples, time_steps, features)
int samples = n - sequenceLength;
double[][] xData = new double[samples][sequenceLength * featureCount];
double[] yData = new double[samples];

for (int i = 0; i < samples; i++) {
    for (int j = 0; j < sequenceLength; j++) {
        for (int k = 0; k < featureCount; k++) {
            xData[i][j * featureCount + k] = normalizedFeatures[i + j][k];
        }
    }
    yData[i] = prices[i + sequenceLength];  // Predict next price
}

// Convert to tensors and reshape
Tensor x = new Tensor(xData);
Tensor y = new Tensor(yData, new Shape(samples));

int trainSize = (int) (samples * 0.8);
Tensor xTrain = x.slice(0, 0, trainSize).reshape(
    trainSize, sequenceLength, featureCount
);
Tensor yTrain = y.slice(0, 0, trainSize);
Tensor xTest = x.slice(0, trainSize, samples).reshape(
    samples - trainSize, sequenceLength, featureCount
);
Tensor yTest = y.slice(0, trainSize, samples);

5. Model Building

5.1: GRU-LSTM Hybrid Model

Sequential model = new Sequential();

// GRU layers - faster training
model.add(new GRU(100, true));
model.add(new Dropout(0.25));

model.add(new GRU(50, true));
model.add(new Dropout(0.2));

// LSTM for final sequence processing
model.add(new LSTM(25, false));

// Dense output layers
model.add(new Dense(32, "relu"));
model.add(new Dropout(0.1));
model.add(new Dense(1, "linear"));

model.compile(
    new MeanSquaredError(),
    new Adam(0.001)
);
Why hybrid GRU+LSTM?
  • GRUs train faster with fewer parameters
  • LSTMs may capture longer dependencies better
  • Hybrid approach: Use GRUs for early layers, LSTM for final sequence capture
  • Alternatively: Try pure GRU for speed, pure LSTM for performance

6. Training

// Callbacks for robust training
EarlyStopping earlyStop = new EarlyStopping("val_loss", 20, true);

);

7. Backtesting Strategy

7.1: Simple Momentum Strategy

Strategy Rules

  • BUY: When predicted price change > +1%
  • SELL: When predicted price change < -1%
  • HOLD: Otherwise
private static void backtest(double[] actual, double[] predicted, 
                                      String outputDir) {
    
    double initialCapital = 10000.0;
    double capital = initialCapital;
    double position = 0.0;
    double entryPrice = 0.0;
    
    List<Double> equityCurve = new ArrayList<>();
    int winTrades = 0;
    int totalTrades = 0;
    
    for (int i = 1; i < actual.length - 1; i++) {
        double predChange = (predicted[i] - predicted[i-1]) / predicted[i-1];
        
        // Buy signal
        if (predChange > 0.01 && position == 0.0) {
            position = capital / actual[i];
            entryPrice = actual[i];
            capital = 0.0;
            totalTrades++;
        } 
        // Sell signal
        else if (predChange < -0.01 && position > 0.0) {
            capital = position * actual[i];
            double profitPct = (actual[i] - entryPrice) / entryPrice;
            if (profitPct > 0) winTrades++;
            position = 0.0;
        }
        
        double currentEquity = capital + position * actual[i];
        equityCurve.add(currentEquity);
    }
    
    // Close any remaining position
    if (position > 0.0) {
        capital = position * actual[actual.length - 1];
        position = 0.0;
    }
    
    double finalReturn = (capital - initialCapital) / initialCapital * 100;
    double winRate = totalTrades > 0 
        ? (double) winTrades / totalTrades * 100 
        : 0;
    
    System.out.printf("Initial Capital:  $%.2f%n", initialCapital);
    System.out.printf("Final Capital:    $%.2f%n", capital);
    System.out.printf("Total Return:     %.2f%%%n", finalReturn);
    System.out.printf("Total Trades:     %d%n", totalTrades);
    System.out.printf("Win Rate:         %.1f%%%n", winRate);
    
    // Plot equity curve
    double[] equityArr = new double[equityCurve.size()];
    for (int i = 0; i < equityArr.length; i++) {
        equityArr[i] = equityCurve.get(i);
    }
    ChartUtils.plotTimeSeries(equityArr, 
        "Equity Curve", 
        outputDir + "/equity_curve.png"
    );
}
Important Backtesting Notes
  • Look-ahead bias: This simplified example uses future knowledge - in real trading you only have past data
  • Transaction costs: Not included - they significantly impact results
  • Slippage: Price movement between decision and execution
  • Overfitting: Past performance does NOT guarantee future results
  • Use walk-forward validation for proper time series cross-validation
