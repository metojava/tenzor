1. Overview

Tenzor provides powerful tools for tracking training progress and visualizing results:

Two Key Components

ClassPurpose
ExecutionMatrixTracks training metrics epoch-by-epoch
ChartUtilsGenerates visualizations using JFreeChart

2. ExecutionMatrix

The ExecutionMatrix is returned by model.fit() and contains comprehensive information about your training run.

2.1: What's Recorded

ExecutionMatrix execMatrix = model.fit(
    xTrain, yTrain, 50, 32, 0.001, 0.15
);

// Print summary
execMatrix.printSummary();

// Print detailed epoch table
execMatrix.printEpochTable();

2.3: Exporting Data

// Export to CSV for analysis in Excel, Python, etc.

execMatrix.save("training/exec_matrix.bin");

// Load later
ExecutionMatrix loaded = ExecutionMatrix.load("training/exec_matrix.bin");

3. ChartUtils

ChartUtils provides static methods to generate various types of charts using the JFreeChart library. All charts are saved as PNG or JPEG files.

3.1: Training History Plots

import com.tenzor.visualization.ChartUtils;

// Plot loss/accuracy curves
ChartUtils.plotTrainingHistory(
    execMatrix.toHistoryMap(),  // Data from ExecutionMatrix
    "Model Training History",             // Chart title
    "charts/training_history.png",        // Output file
    1000,                               // Width (optional)
    600                                 // Height (optional)
);
What's Plotted

This method will plot all available metrics from the history map:

  • loss - Training loss curve
  • val_loss - Validation loss curve (if available)
  • accuracy - Training accuracy (if available)
  • val_accuracy - Validation accuracy (if available)

3.2: Predictions vs Actual

4. Complete Workflow Example

Here's a complete example showing how to use both ExecutionMatrix and ChartUtils:

package com.tenzor.examples;

import com.tenzor.core.Tensor;
import com.tenzor.datasets.FashionMNIST;
import com.tenzor.nn.Sequential;
import com.tenzor.nn.layers.*;
import com.tenzor.nn.losses.*;
import com.tenzor.nn.optimizers.*;
import com.tenzor.training.ExecutionMatrix;
import com.tenzor.visualization.ChartUtils;
import com.tenzor.callbacks.*;
import com.tenzor.metrics.Accuracy;

import java.io.IOException;
import java.nio.file.*;

public class VisualizationExample {
    public static void main(String[] args) throws Exception {
        
        // Create output directory
        String outputDir = "output/fashion_mnist_visual";
        Files.createDirectories(Paths.get(outputDir));

        // 1. Load data
        System.out.println("Loading Fashion MNIST...");
        FashionMNIST dataset = new FashionMNIST();
        Tensor xTrain = dataset.getXTrain();
        Tensor yTrain = dataset.getYTrain();
        Tensor xTest = dataset.getXTest();
        Tensor yTest = dataset.getYTest();

        // 2. Build model
        Sequential model = new Sequential();
        model.add(new Dense(256, "relu"));
        model.add(new Dropout(0.3));
        model.add(new Dense(128, "relu"));
        model.add(new Dropout(0.2));
        model.add(new Dense(10, "softmax"));

        model.compile(
            new SparseCategoricalCrossentropy(),
            new Adam(0.001)
        );

        // 3. Set up callbacks
        EarlyStopping earlyStop = new EarlyStopping("val_loss", 10, true);
        ReduceLROnPlateau reduceLr = new ReduceLROnPlateau("val_loss", 0.5, 5, 1e-7);

        // 4. Train - returns ExecutionMatrix
        System.out.println("\nTraining model...");
        ExecutionMatrix execMatrix = model.fit(
            xTrain, yTrain,     // data
            50,                 // epochs
            64,                 // batch size
            0.001,              // learning rate
            0.15,               // validation split
            earlyStop, reduceLr  // callbacks
        );

        // 5. Print training summary
        System.out.println("\nTraining Summary:");
        execMatrix.printSummary();

        // 6. Export training data
        execMatrix.exportToCSV(outputDir + "/training_log.csv");

        // 7. Generate charts
        System.out.println("\nGenerating charts...");

        // Training history
        ChartUtils.plotTrainingHistory(
            execMatrix.toHistoryMap(),
            "Fashion MNIST Training",
            outputDir + "/training_history.png",
            1000, 600
        );

        // 8. Evaluate and visualize predictions
        System.out.println("\nEvaluating on test set...");
        model.printEvaluation(xTest, yTest);

        Tensor predictions = model.predict(xTest);
        double[] actual = yTest.getData();
        double[] predProbs = predictions.getData();

        // Convert probabilities to class predictions
        int[] predLabels = argmaxPerRow(predProbs, 10);
        double[] predDoubles = new double[predLabels.length];
        for (int i = 0; i < predLabels.length; i++) {
            predDoubles[i] = predLabels[i];
        }

        // Plot sample of predictions
        int sampleSize = Math.min(200, actual.length);
        double[] actualSample = new double[sampleSize];
        double[] predSample = new double[sampleSize];
        for (int i = 0; i < sampleSize; i++) {
            actualSample[i] = actual[i];
            predSample[i] = predDoubles[i];
        }

        ChartUtils.plotPredictions(
            actualSample,
            predSample,
            "Classification Results (First 200 samples)",
            outputDir + "/predictions.png"
        );

        // Calculate and plot errors
        double[] errors = new double[actual.length];
        for (int i = 0; i < actual.length; i++) {
            errors[i] = (actual[i] == predDoubles[i]) ? 0.0 : 1.0;
        }

        ChartUtils.plotHistogram(
            errors,
            "Error Distribution",
            "Error (0=correct, 1=incorrect)",
            outputDir + "/error_histogram.png",
            2
        );

        System.out.println("\nDone! Results saved to: " + outputDir);
    }

    private static int[] argmaxPerRow(double[] probs, int numClasses) {
        int[] result = new int[probs.length / numClasses];
        for (int i = 0; i < result.length; i++) {
            int maxIdx = 0;
            double maxVal = probs[i * numClasses];
            for (int j = 1; j < numClasses; j++) {
                if (probs[i * numClasses + j] > maxVal) {
                    maxVal = probs[i * numClasses + j];
                    maxIdx = j;
                }
            }
            result[i] = maxIdx;
        }
        return result;
    }
}

5. Output File Structure

When you run the visualization example, you'll get:

Generated Files

output/fashion_mnist_visual/
├── training_history.png      # Loss/accuracy curves
├── predictions.png           # Predictions vs actual (scatter)
├── error_histogram.png       # Error distribution
├── training_log.csv          # Full training log for analysis
└── best_model.json           # Best model (from EarlyStopping)
Using CSV in Excel/Python

The CSV file can be opened in Excel or analyzed with Python's pandas: 

# Python example
import pandas as pd
df = pd.read_csv('training_log.csv')
print(df.head())
