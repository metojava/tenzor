2. Sequential Model

What is the Sequential model?

The Sequential class is a linear stack of layers. It's the simplest way to build a neural network - you just add layers one after another.

2.1: Creating a Sequential Model

// Create empty model
Sequential model = new Sequential();

// Add layers
model.add(new Dense(256, "relu"));
model.add(new Dropout(0.3));
model.add(new Dense(10, "softmax"));

3. Layers

Layer Purpose Example
Dense Fully connected layer - every input connected to every output new Dense(64, "relu")
Dropout Regularization - randomly sets inputs to 0 during training new Dropout(0.2)
Flatten Flattens multi-dimensional input to 1D new Flatten()
BatchNormalization Normalizes layer inputs, stabilizes training new BatchNormalization()
LSTM Long Short-Term Memory - for sequence data new LSTM(50, true)
GRU Gated Recurrent Unit - simpler LSTM alternative new GRU(32, false)
Conv2D 2D Convolution - for images new Conv2D(32, 3, "relu")
MaxPooling2D Max pooling - reduces spatial dimensions new MaxPooling2D(2)
Embedding Turns integers into dense vectors - for text new Embedding(1000, 64)

3.1: Dense Layer Deep Dive

Dense Layer Parameters

Dense(int units, String activation)

// units:       Number of neurons/output units
// activation:  Activation function ("relu", "sigmoid", "tanh", "softmax", "linear")

// Examples:
new Dense(128, "relu");      // Hidden layer with ReLU
new Dense(1, "sigmoid");      // Binary classification output
new Dense(10, "softmax");     // Multi-class classification (10 classes)
new Dense(1, "linear");       // Regression output

3.2: Recurrent Layers (LSTM, GRU)

When to use LSTMs

Use LSTMs and GRUs for sequential data: time series, text, speech, or any data where order matters. 

// LSTM for time series
Sequential model = new Sequential();

// LSTM(units, return_sequences)
// return_sequences=true: pass full sequence to next recurrent layer
model.add(new LSTM(64, true));   // First LSTM returns sequences
model.add(new Dropout(0.2));
model.add(new LSTM(32, false));  // Final LSTM returns only last output
model.add(new Dense(1));            // Predict single value

// Input shape expected: (samples, time_steps, features)
// Example: 100 samples, 30 time steps, 5 features
Tensor input = xTrain.reshape(100, 30, 5);

4. Activation Functions

Function Formula Use Case Output Range
ReLU max(0, x) Hidden layers (most common) [0, ∞)
Sigmoid 1 / (1 + e^(-x)) Binary classification [0, 1]
Tanh tanh(x) RNNs, normalized inputs [-1, 1]
Softmax e^xi / Σ(e^xj) Multi-class classification [0, 1] (sums to 1)
Linear x Regression output (-∞, ∞)
Choosing the Right Activation
  • Hidden layers: Use ReLU - it helps with vanishing gradients
  • Binary classification output: Use sigmoid
  • Multi-class classification: Use softmax
  • Regression: Use linear (no activation)

5. Loss Functions

The loss function measures how far the model's predictions are from the actual values. The optimizer uses this loss to update the model's weights.

Loss Function Problem Type Description
MeanSquaredError (MSE) Regression Average of squared differences
MeanAbsoluteError (MAE) Regression Average of absolute differences
Huber Regression Less sensitive to outliers than MSE
BinaryCrossentropy Binary Classification For 2 classes (0/1)
CategoricalCrossentropy Multi-class Classification For one-hot encoded labels
SparseCategoricalCrossentropy Multi-class Classification For integer labels (0, 1, 2...)
Hinge Classification For SVM-like margins 
// Regression
model.compile(new MeanSquaredError(), new Adam());

// Binary classification (labels: 0 or 1)
model.compile(new BinaryCrossentropy(), new Adam());

// Multi-class classification with integer labels
// Example: Fashion MNIST labels: 0, 1, 2, ..., 9
model.compile(new SparseCategoricalCrossentropy(), new Adam());

// Multi-class with one-hot encoded labels
// Example: labels = [[1,0,0], [0,1,0], ...]
model.compile(new CategoricalCrossentropy(), new Adam());

6. Optimizers

Optimizers update the model's weights to minimize the loss. Different optimizers use different strategies for this.

Optimizer Description When to Use
SGD Stochastic Gradient Descent Simple, good for large datasets
Adam Adaptive Moment Estimation Default choice - works well for most problems
RMSprop Root Mean Square Propagation Good for RNNs, online learning
Adagrad Adaptive Gradient Sparse data, large feature spaces
Adadelta Adadelta Continues learning over time 
// Adam is usually the best default
model.compile(loss, new Adam(0.001));

// SGD with momentum
model.compile(loss, new SGD(0.01, 0.9));  // lr=0.01, momentum=0.9

// RMSprop
model.compile(loss, new RMSprop(0.001));
Learning Rate Guidelines
  • 0.001 - Good default for Adam
  • 0.01 - Good default for SGD
  • Too high → Model doesn't converge, loss oscillates
  • Too low → Training is slow, may get stuck in local minimum

7. Callbacks

Callbacks are objects that perform actions at different stages of training. They can monitor metrics, save models, stop training early, and more.

Callback Purpose Example
EarlyStopping Stop training when validation loss stops improving new EarlyStopping("val_loss", 10, true)
ModelCheckpoint Save model at certain intervals new ModelCheckpoint("best.json", "val_loss", true)
ReduceLROnPlateau Reduce learning rate when metric plateaus new ReduceLROnPlateau("val_loss", 0.5, 5, 1e-7) 
// Create callbacks
EarlyStopping earlyStop = new EarlyStopping(
    "val_loss",      // Monitor validation loss
    10,                 // Wait 10 epochs before stopping
    true                // Restore weights from best epoch
);

ModelCheckpoint checkpoint = new ModelCheckpoint(
    "models/best_model.json",  // Save path
    "val_loss",              // Monitor this metric
    true                        // Save only when improvement
);

ReduceLROnPlateau reduceLr = new ReduceLROnPlateau(
    "val_loss",      // Monitor
    0.5,                // Multiply lr by 0.5
    5,                  // Wait 5 epochs
    1e-8                 // Minimum learning rate
);

// Use callbacks in fit()
model.fit(xTrain, yTrain, 100, 32, 0.001, 0.1,
    earlyStop, checkpoint, reduceLr
);

fit() Parameters

    xTrain,                 // Training features
    yTrain,                 // Training labels
    epochs,                 // Number of epochs
    batchSize,              // Batch size

    validationSplit,        // Fraction for validation (0.1 = 10%)
    callbacks...            // Optional: varargs of callbacks
);

8.3: Understanding the Training Output

Epoch  | Train Loss   | Val Loss     | Train Acc    | Val Acc      | Duration  
----------------------------------------------------------------------------------------------------
1/50   | 0.824074     | 0.543210     | 0.7123       | 0.8234       | 0.45s     
2/50   | 0.432109     | 0.321098     | 0.8456       | 0.8876       | 0.42s     
3/50   | 0.321098     | 0.287654     | 0.8876       | 0.9012       | 0.41s
Column Meaning
Epoch Current epoch / Total epochs
Train Loss Loss on training data (should decrease)
Val Loss Loss on validation data (watch for increase = overfitting)
Train Acc Accuracy on training data
Val Acc Accuracy on validation data
Duration Time taken for this epoch
Overfitting Warning Signs
  • Train loss continues to decrease but validation loss increases
  • Train accuracy is much higher than validation accuracy
  • Solution: Add Dropout layers, reduce model size, use EarlyStopping

// Class 5 has highest probability (0.6)

10. Saving & Loading Models

10.1: Save Model

import com.tenzor.io.ModelSaver;

// Save to JSON
ModelSaver.save(model, "models/my_model.json");

10.2: Load Model

import com.tenzor.io.ModelLoader;

// Load from JSON
Sequential loadedModel = ModelLoader.load("models/my_model.json");

// Use the loaded model
Tensor predictions = loadedModel.predict(xTest);

10.3: ExecutionMatrix Saving

ExecutionMatrix execMatrix = model.fit(...);

// Export to CSV for analysis in Excel/Python
execMatrix.exportToCSV("training/training_log.csv");

// Save and load binary format
execMatrix.save("training/exec_matrix.bin");
ExecutionMatrix loaded = ExecutionMatrix.load("training/exec_matrix.bin");

10.4: ExecutionMatrix Methods

Method Description
printSummary() Print summary of best metrics and total time
printEpochTable() Print table of all epochs
getBestTrainLoss() Best training loss achieved
getBestValidationLoss() Best validation loss achieved
getEpochWithBestValLoss() Epoch number with best validation
getTotalTrainingTimeMs() Total training duration in milliseconds
toHistoryMap() Convert to format for ChartUtils
