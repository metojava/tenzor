1. What is Fashion MNIST?

Fashion MNIST is a dataset of Zalando's article images - consisting of a training set of 60,000 examples and a test set of 10,000 examples. Each example is a 28x28 grayscale image, associated with a label from 10 classes.

Fashion MNIST Classes
LabelClassDescription
0T-shirt/topT-shirts, tops
1TrouserPants, jeans
2PulloverSweaters

5SandalSandals

8BagBags
9Ankle bootAnkle boots

Why Fashion MNIST?

Fashion MNIST is meant to be a drop-in replacement for the classic MNIST handwritten digits dataset. It's more challenging (classic MNIST is "too easy" for modern models) while maintaining the same data format (28x28 grayscale images, 10 classes).

2. Dataset Format (IDX)

Fashion MNIST is stored in the IDX format - a binary format designed for vectors and multidimensional arrays. Tenzor's FashionMNIST class handles all this automatically.

3. Automatic Download & Loading

Tenzor's FashionMNIST class will automatically download the dataset from GitHub if it's not already present locally. 

import com.tenzor.datasets.FashionMNIST;
import com.tenzor.core.Tensor;

// Downloads and loads the dataset
// Data will be cached in temp/fashion_mnist/
FashionMNIST dataset = new FashionMNIST();

// Get the data as Tensors
Tensor xTrain = dataset.getXTrain();  // Shape(60000, 784) - flattened 28x28
Tensor yTrain = dataset.getYTrain();  // Shape(60000) - labels 0-9
Tensor xTest = dataset.getXTest();   // Shape(10000, 784)
Tensor yTest = dataset.getYTest();   // Shape(10000)

System.out.println("Train: " + xTrain.shape());
System.out.println("Test:  " + xTest.shape());

4. Data Preprocessing

The images are already normalized (pixel values 0-1). Each 28x28 image is flattened to a 784-element vector.

Data Shape Breakdown

OriginalFlattenedValues
28 x 28 pixels784 elements0.0 to 1.0
Why flatten?

The Dense (fully connected) layers expect 1D vectors as input (after the batch dimension). For CNNs, you would keep the 2D structure (28, 28, 1) for grayscale or (28, 28, 3) for RGB.

5. Building the Model

Let's build a neural network with multiple layers, batch normalization, and dropout for regularization. 

import com.tenzor.nn.Sequential;
import com.tenzor.nn.layers.*;
import com.tenzor.nn.losses.*;
import com.tenzor.nn.optimizers.*;
import com.tenzor.callbacks.*;

// Create model
Sequential model = new Sequential();

// Input: 784 features (flattened 28x28)

// Hidden layer 1: 256 neurons with ReLU + BatchNorm + Dropout
model.add(new Dense(256, "relu"));
model.add(new BatchNormalization());
model.add(new Dropout(0.3));

// Hidden layer 2: 128 neurons
model.add(new Dense(128, "relu"));
model.add(new BatchNormalization());
model.add(new Dropout(0.2));

// Hidden layer 3: 64 neurons
model.add(new Dense(64, "relu"));
model.add(new Dropout(0.2));

// Output: 10 classes with softmax (probabilities)
model.add(new Dense(10, "softmax"));

// Compile
model.compile(
    new SparseCategoricalCrossentropy(),  // For integer labels (0-9)
    new Adam(0.001)                    // Adam optimizer with LR=0.001
);
Layer Explanations
LayerPurpose
Dense(256, "relu")Fully connected layer with ReLU activation
BatchNormalizationNormalizes layer inputs, stabilizes training
Dropout(0.3)Randomly drops 30% of neurons to prevent overfitting
Dense(10, "softmax")Outputs probabilities for 10 classes
SparseCategoricalCrossentropy vs CategoricalCrossentropy
  • SparseCategoricalCrossentropy: Use when labels are integers (0, 1, 2, ..., 9)
  • CategoricalCrossentropy: Use when labels are one-hot encoded

Fashion MNIST labels are integers (0-9), so we use SparseCategoricalCrossentropy.

6. Setting Up Callbacks

Callbacks let you perform actions during training. We'll use: 

// Stop if validation loss doesn't improve for 10 epochs
EarlyStopping earlyStop = new EarlyStopping(
    "val_loss",     // Metric to monitor
    10,              // Patience: wait 10 epochs
    true              // Restore best weights when stopping
);

// Save model when validation loss improves
ModelCheckpoint checkpoint = new ModelCheckpoint(
    "output/fashion_mnist/best_model.json",
    "val_loss",
    true              // Only save on improvement
);

// Reduce learning rate when validation plateaus
ReduceLROnPlateau reduceLr = new ReduceLROnPlateau(
    "val_loss",     // Monitor
    0.5,              // Multiply LR by 0.5
    5,               // Wait 5 epochs
    1e-8              // Minimum LR
);

7. Training the Model

import com.tenzor.training.ExecutionMatrix;
import java.nio.file.*;

// Create output directory
Files.createDirectories(Paths.get("output/fashion_mnist"));

// Train!
System.out.println("\nTraining model...");

ExecutionMatrix execMatrix = model.fit(
    xTrain, yTrain,           // Training data
    50,                       // Maximum epochs
    64,                       // Batch size
    0.001,                    // Learning rate
    0.15,                     // Use 15% of training data for validation
    earlyStop, checkpoint, reduceLr  // Callbacks
);

// Print summary
execMatrix.printSummary();

// Export training log
execMatrix.exportToCSV("output/fashion_mnist/training_log.csv");

What You'll See in Training History

  • Train Loss should steadily decrease
  • Val Loss should decrease then flatten
  • If val loss increases while train loss decreases = OVERFITTING
  • Solution: Add more dropout, reduce model size, use EarlyStopping

10. Making Predictions

import com.tenzor.core.Tensor;
import com.tenzor.metrics.Accuracy;

// Get predictions
Tensor predictions = model.predict(xTest);

// Predictions are probabilities - shape (10000, 10)
// Each row has 10 values summing to 1.0 (softmax output)

// Convert probabilities to class labels
String[] classNames = {
    "T-shirt/top", "Trouser", "Pullover", "Dress", "Coat",
    "Sandal", "Shirt", "Sneaker", "Bag", "Ankle boot"
};

// Get class with highest probability for first 10 samples
double[] predData = predictions.getData();
double[] actualData = yTest.getData();

System.out.println("\nSample Predictions:");
System.out.println("-".repeat(70));
System.out.printf("%6s | %-15s | %-15s | %s%n",
    "Index", "Actual", "Predicted", "Correct?");
System.out.println("-".repeat(70));

for (int i = 0; i < Math.min(15, actualData.length); i++) {
    // Find argmax for this sample's 10 probabilities
    int predLabel = 0;
    double maxProb = predData[i * 10];
    for (int j = 1; j < 10; j++) {
        if (predData[i * 10 + j] > maxProb) {
            maxProb = predData[i * 10 + j];
            predLabel = j;
        }
    }
    
    int actualLabel = (int) actualData[i];
    String correct = (actualLabel == predLabel) ? "✓" : "✗";
    
    System.out.printf("%6d | %-15s | %-15s | %s%n",
        i, classNames[actualLabel], classNames[predLabel], correct);
}

13. Common Issues & Solutions

ProblemSolution
Model not learning (loss doesn't decrease) Check learning rate (try 0.001 for Adam), check data normalization
Overfitting (train acc >> val acc) Add dropout layers, reduce model size, use EarlyStopping
Training is slow Increase batch size, reduce epochs (use EarlyStopping)
Download fails Check internet, or manually download files to temp/fashion_mnist/
