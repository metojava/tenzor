1. Overview

What is Time Series Forecasting?

Time series forecasting is the task of predicting future values based on historical time-ordered data. Unlike traditional ML, order matters significantly in time series.

2. Data Generation

2.1: Synthetic Time Series

// Generate various time series components
int nPoints = 1000;

// Sine wave (periodic component)
double[] sine = SequenceGenerator.generateSineWave(
    nPoints,    // total points
    50,         // period
    1.0,        // amplitude
    0           // phase offset
);

// Linear trend
double[] trend = SequenceGenerator.generateLinearTrend(
    nPoints,
    0.0,    // start value
    0.002   // slope
);

// Random walk (stochastic component)
double[] noise = SequenceGenerator.generateRandomWalk(
    nPoints,
    0,      // start
    0.1     // step size
);

// Combine components
double[] combined = new double[nPoints];
for (int i = 0; i < nPoints; i++) {
    combined[i] = sine[i] + trend[i] + 0.5 * noise[i];
}

// Visualize
ChartUtils.plotTimeSeries(combined, 
    "Combined Time Series", 
    "output/series.png");

Why synthetic data?

  • Quick prototyping and testing
  • Understand model behavior on known patterns
  • Verify model can capture periodicity, trend, and noise
  • Controlled experiments

Important Note on Scaling
  • Always normalize/scale data for neural networks
  • Use only training data to fit your scalers
  • Apply the same scaler to test data
  • Denormalize predictions for meaningful error metrics

5. LSTM Model Architecture

5.1: Building an LSTM Model

Sequential model = new Sequential();

// First LSTM layer - return_sequences=true for stacked LSTM
model.add(new LSTM(
    64,      // units/neurons
    true      // return_sequences: pass full sequence to next layer
));
model.add(new Dropout(0.2));  // Regularization

// Second LSTM layer
model.add(new LSTM(32, false));  // return_sequences=false for final LSTM
model.add(new Dropout(0.1));

// Dense layers for output
model.add(new Dense(16, "relu"));
model.add(new Dense(1, "linear"));  // Regression output

// Compile
model.compile(
    new MeanSquaredError(),
    new Adam(0.001)
);
LSTM vs GRU
AspectLSTMGRU
Gates3 (input, forget, output)2 (update, reset)
ComplexityHigherLower
Training SpeedSlowerFaster
MemoryCell state + hidden stateHidden state only

Rule of thumb: Try GRU first for faster iteration, use LSTM if you need maximum performance on long sequences.

6.1: Setting Up Callbacks

// Early stopping to prevent overfitting
EarlyStopping earlyStop = new EarlyStopping(
    "val_loss",    // Monitor validation loss
    15,              // Patience: wait 15 epochs before stopping
    true             // Restore best weights
);

// Save best model during training

    "output/best_model.json",
    "val_loss",
    true
);

// Reduce learning rate when plateau
ReduceLROnPlateau reduceLr = new ReduceLROnPlateau(
    "val_loss",    // Monitor
    0.7,             // Factor: multiply LR by 0.7

);

    xTrain, yTrain,

8. Multi-step Forecasting

8.1: Recursive Multi-step

Recursive Strategy

Predict one step ahead, then use that prediction as input to predict the next step. Repeat for N steps. 

private static double[] multiStepForecast(
        Sequential model, Tensor initialInput, 
        int steps, int seqLength) {
    
    double[] forecast = new double[steps];
    Tensor current = initialInput.slice(0, 0, 1);  // First sample
    
    for (int i = 0; i < steps; i++) {
        Tensor pred = model.predict(current);
        forecast[i] = pred.get(0);
        
        // Shift window: remove oldest, add prediction
        double[] currentData = current.getData();
        double[] newData = new double[currentData.length];
        
        System.arraycopy(currentData, 1, newData, 0, currentData.length - 1);
        newData[newData.length - 1] = forecast[i];
        
        current = new Tensor(newData, new Shape(1, seqLength, 1));
    }
    
    return forecast;
}

// Usage
double[] forecast = multiStepForecast(model, xTest, 10, sequenceLength);
