What is Tenzor?

Tenzor is a comprehensive Java machine learning library that provides two main APIs:

  • TensorFlow Keras-like API - For building and training neural networks
  • scikit-learn-like API - For traditional machine learning algorithms

Why Tenzor?

Tenzor brings the familiarity of Python ML frameworks (TensorFlow, scikit-learn) to Java developers. No Python installation required - pure Java implementation.

Key Features

🔢 Tensor Core

N-dimensional arrays with broadcasting, math operations, activation functions, and matrix operations.

🧠 Neural Networks

Dense, Conv2D, LSTM, GRU, RNN layers, Dropout, BatchNormalization, and multiple optimizers.

🌲 Traditional ML

Random Forest, Decision Trees, SVM, KNN, Linear Regression, Logistic Regression, and more.

📊 Visualization

JFreeChart integration for training history, predictions, scatter plots, histograms, and residuals.

📈 Time Series

Sequence generation, technical indicators (RSI, MACD, Bollinger Bands), and stock data loading.

💾 Model Persistence

Save and load models in JSON format. Training checkpoints and execution matrix tracking.

Quick Start

1. Build the Library

# Clone or navigate to the Tenzor directory
cd tenzor

# Build with Maven
mvn clean package

# Run tests
mvn test

2. Maven Dependency

<dependency>
    <groupId>com.tenzor</groupId>
    <artifactId>tenzor</artifactId>
    <version>1.0.0</version>
</dependency>

3. Neural Network Example

import com.tenzor.core.Tensor;
import com.tenzor.nn.Sequential;
import com.tenzor.nn.layers.*;
import com.tenzor.nn.losses.*;
import com.tenzor.nn.optimizers.*;
import com.tenzor.training.ExecutionMatrix;

// Build a neural network
Sequential model = new Sequential();
model.add(new Dense(128, "relu"));
model.add(new Dropout(0.2));
model.add(new Dense(64, "relu"));
model.add(new Dense(10, "softmax"));

// Compile the model
model.compile(
    new SparseCategoricalCrossentropy(), 
    new Adam(0.001)
);

// Train - returns ExecutionMatrix for tracking
ExecutionMatrix execMatrix = model.fit(
    xTrain, yTrain,    // training data
    50,                // epochs
    32,                // batch size
    0.001,             // learning rate
    0.15               // validation split (15%)
);

// Print detailed training summary
execMatrix.printSummary();
execMatrix.printEpochTable();

// Generate visualization
ChartUtils.plotTrainingHistory(
    execMatrix.toHistoryMap(),
    "Training History",
    "charts/training.png"
);

// Predict and evaluate
Tensor predictions = model.predict(xTest);
model.printEvaluation(xTest, yTest);

4. scikit-learn Style Example

import com.tenzor.core.Tensor;
import com.tenzor.sklearn.ensemble.*;
import com.tenzor.sklearn.preprocessing.*;
import com.tenzor.sklearn.model_selection.*;
import com.tenzor.metrics.*;

// Split data
Tensor[] split = train_test_split.split(X, y, 0.3, 42);

// Preprocess
StandardScaler scaler = new StandardScaler();
Tensor X_train_scaled = scaler.fitTransform(split[0]);
Tensor X_test_scaled = scaler.transform(split[1]);

// Train Random Forest
RandomForestClassifier rf = new RandomForestClassifier(
    100,    // n_estimators
    10,     // max_depth
    2       // min_samples_split
);
rf.fit(X_train_scaled, split[2]);

// Predict
Tensor predictions = rf.predict(X_test_scaled);
double accuracy = Accuracy.compute(split[3], predictions);

System.out.println("Accuracy: " + accuracy);

Project Structure

tenzor/
├── src/main/java/com/tenzor/
│   ├── core/              // Tensor, Variable, Shape, TensorMath
│   ├── nn/               // Sequential, layers, losses, optimizers
│   ├── sklearn/          // scikit-learn style estimators
│   ├── datasets/         // Built-in datasets (MNIST, FashionMNIST, etc.)
│   ├── timeseries/       // Time series utilities
│   ├── metrics/          // Evaluation metrics
│   ├── visualization/    // ChartUtils (JFreeChart)
│   ├── training/         // ExecutionMatrix
│   ├── io/               // Model saving/loading
│   ├── callbacks/        // EarlyStopping, ModelCheckpoint
│   └── data/             // Data loading
├── examples/            // Runnable example programs
├── docs/                // Markdown documentation
├── docs-html/           // This HTML tutorial
└── pom.xml              // Maven build file

API Comparison

Concept TensorFlow (Python) Tenzor (Java)
Sequential model tf.keras.Sequential() new Sequential()
Dense layer Dense(128, activation='relu') new Dense(128, "relu")
Dropout Dropout(0.2) new Dropout(0.2)
LSTM LSTM(50, return_sequences=True) new LSTM(50, true)
Adam optimizer optimizer=tf.keras.optimizers.Adam() new Adam(0.001)
Random Forest RandomForestClassifier() new RandomForestClassifier()
train_test_split train_test_split(X, y) train_test_split.split(X, y)
StandardScaler StandardScaler() new StandardScaler()
